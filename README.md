## Read this first

Planned. Nothing to install here, and no date. What exists today is an idea and a place to argue about it.

## The idea

Environment tools for cinematic skies, soft volumes, atmospheric depth, and scene building. The target is a sky you can adjust in a minute instead of a volume shader you tune for an afternoon and then can't reproduce a week later.

## What's decided and what isn't

Settled: environment focus, and working with Blender's own render engines rather than around them.

Open: whether this should be volumetric presets, a node-based sky builder, or a smaller set of atmosphere utilities. Volumetrics are expensive to render and slow to iterate, so the interface question matters as much as the feature list.

## Available right now

For HDRI and material work there's the [BlendKit profile](https://www.blendkit.com/?query=author_id:205846), which is where the shaders and environment assets live. Cloud Studio wouldn't replace those; it would be the tool that builds around them.

[Open an issue](https://github.com/pacosalasv/DRH_Cloud_Studio-Support/issues) with the sky you keep rebuilding. Reference frames help more than descriptions.
